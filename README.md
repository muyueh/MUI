# Joy UI Messages Template

This repository packages the [Joy UI Messages template](https://github.com/mui/material-ui/tree/master/docs/data/joy/getting-started/templates/messages) so it can be hosted directly from GitHub Pages.

## Scripts

- `npm install` – install dependencies.
- `npm run dev` – start a local development server with Vite.
- `npm run build` – type-check the project and create the production build in `dist/`.
- `npm run preview` – preview the production build locally.

## Deploying to GitHub Pages

1. Run `npm run build` to generate the static assets in `dist/`.
2. Publish the `dist` directory using your preferred GitHub Pages workflow (e.g., `gh-pages` branch or the `pages` deployment action). Make sure only text assets are committed; no binary files are required.
